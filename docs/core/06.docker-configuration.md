## 1. `Dockerfile` — Ana Uygulama

| Özellik         | Değer                                          |
| --------------- | ---------------------------------------------- |
| **Base image**  | `node:22-alpine`                               |
| **Aşama**       | Çok aşamalı (multi-stage): builder → runtime   |
| **Güvenlik**    | Non-root kullanıcı (`appuser`)                  |
| **Sağlık**      | `HEALTHCHECK` ile otomatik durum kontrolü       |

### Dockerfile Formatı — Temel Kurallar

```dockerfile
# Her Dockerfile bir FROM ile başlar (base image)
FROM node:22-alpine AS builder

# WORKDIR — çalışma dizini belirler
WORKDIR /app

# COPY — dosya kopyalar (host → container)
COPY package.json ./

# RUN — komut çalıştırır (build zamanında)
RUN npm ci

# ENV — ortam değişkeni tanımlar
ENV NODE_ENV=production

# EXPOSE — hangi port'u dinlediğimi belirtir (bilgi amaçlı)
EXPOSE 3000

# CMD — container başlatıldığında çalışacak komut
CMD ["node", "src/index.js"]
```

### Multi-Stage (Çok Aşamalı) Build Nedir?

```
┌─── Builder Aşaması ───────────────────────┐
│ • Tüm bağımlılıkları kur                  │
│ • Kaynak kodu derle                        │
│ • devDependencies dahil (~800 MB)          │
└────────────────────────┬──────────────────┘
                         │ Sadece gerekli dosyalar
                         ▼
┌─── Runtime Aşaması ───────────────────────┐
│ • Sadece production bağımlılıkları         │
│ • Derlenmiş çıktı                          │
│ • Küçük ve güvenli imaj (~150 MB)          │
└───────────────────────────────────────────┘
```

> **Neden?** Build araçları (TypeScript compiler vb.) production'da gereksiz.
> Multi-stage ile son imaj küçük ve temiz kalır.

## 5. `docker-compose.yml` — Orkestrasyon

Docker Compose birden fazla container'ı **tek komutla** yönetir.

### Dosya Formatı — YAML

```yaml
# YAML = YAML Ain't Markup Language
# Girintileme (indentation) ÖNEMLİ — TAB değil, BOŞLUK kullanılır
services:
  servis-adi:
    build:                        # Nasıl derlenir
      context: .
      dockerfile: Dockerfile
    ports:                        # Port eşlemesi (host:container)
      - "3000:3000"
    env_file:                     # Ortam değişkenleri dosyası
      - .env
    volumes:                      # Dosya paylaşımı (host:container)
      - ./src:/app/src
    networks:                     # Ağ bağlantısı
      - app-net
    profiles:                     # İsteğe bağlı başlatma
      - security
```

### Tanımlı Servisler

| Servis            | Dockerfile                     | Profil     | Açıklama                  |
| ----------------- | ------------------------------ | ---------- | ------------------------- |
| `app`             | `Dockerfile`                   | (varsayılan) | Ana uygulama            |
| `sandbox`         | `Dockerfile.sandbox`           | `security` | CLI güvenlik ortamı       |
| `sandbox-browser` | `Dockerfile.sandbox-browser`   | `security` | Tarayıcı güvenlik ortamı  |

### Profil Sistemi

`sandbox` ve `sandbox-browser` her zaman başlatılmaz — sadece `--profile security` ile:

```bash
# Sadece ana uygulama
docker compose up

# Ana uygulama + sandbox'lar
docker compose --profile security up
```

## 6. `docker-setup.sh` — Kurulum Betiği

İlk kez çalıştırıldığında ortamı hazırlar:

```bash
chmod +x docker-setup.sh
./docker-setup.sh
```

### Ne Yapar?

1. Docker ve Docker Compose kurulu mu kontrol eder
2. `.env` dosyası yoksa `.env.example`'dan kopyalar
3. `workspace/` dizinini oluşturur
4. `sandbox-common` base image'ı derler
5. Tüm servisleri `docker compose build` ile derler

---

## 7. `.dockerignore` — Build Context Dışlama

Docker `build` komutu çalışırken tüm proje dizinini ("context") Docker daemon'a
gönderir. `.dockerignore` gereksiz dosyaları **dışlayarak**:

- Build süresini kısaltır
- Image boyutunu küçültür
- Secret'ların image'a sızmasını engeller

## Sık Kullanılan Komutlar

| Komut                                        | Açıklama                            |
| -------------------------------------------- | ----------------------------------- |
| `docker compose up`                          | Tüm servisleri başlat               |
| `docker compose up -d`                       | Arka planda başlat                  |
| `docker compose up app`                      | Sadece uygulamayı başlat            |
| `docker compose --profile security up`       | Sandbox'larla birlikte başlat       |
| `docker compose down`                        | Tüm servisleri durdur               |
| `docker compose logs -f app`                 | Uygulama loglarını takip et         |
| `docker compose build`                       | Tüm imajları yeniden derle          |
| `docker compose build --no-cache`            | Cache'siz sıfırdan derle            |
| `docker compose exec sandbox bash`           | Sandbox'a terminal aç              |
| `docker compose exec sandbox-browser bash`   | Tarayıcı sandbox'a terminal aç     |
| `docker compose ps`                          | Çalışan servisleri listele          |

## Dockerfile Komut Referansı

| Komut          | Ne Yapar                                                    | Örnek                                |
| -------------- | ----------------------------------------------------------- | ------------------------------------ |
| `FROM`         | Base image seçer (her Dockerfile bununla başlar)             | `FROM node:22-alpine`                |
| `WORKDIR`      | Çalışma dizinini belirler                                    | `WORKDIR /app`                       |
| `COPY`         | Host'tan container'a dosya kopyalar                          | `COPY package.json ./`               |
| `ADD`          | COPY + tar açma + URL indirme (COPY tercih edilir)           | `ADD archive.tar.gz /app/`           |
| `RUN`          | Build zamanında komut çalıştırır                             | `RUN npm ci`                         |
| `CMD`          | Container başlatıldığında çalışan varsayılan komut           | `CMD ["node", "index.js"]`           |
| `ENTRYPOINT`   | CMD'den önce çalışan sabit komut                            | `ENTRYPOINT ["python3"]`             |
| `ENV`          | Ortam değişkeni tanımlar                                     | `ENV NODE_ENV=production`            |
| `EXPOSE`       | Hangi port'u dinlediğini belirtir (bilgi amaçlı)             | `EXPOSE 3000`                        |
| `VOLUME`       | Kalıcı veri noktası tanımlar                                 | `VOLUME ["/data"]`                   |
| `USER`         | Hangi kullanıcı olarak çalışacağını belirler                 | `USER appuser`                       |
| `HEALTHCHECK`  | Container sağlık kontrolü tanımlar                           | `HEALTHCHECK CMD curl localhost`     |
| `ARG`          | Build zamanında değişken alır (`--build-arg`)                | `ARG VERSION=latest`                 |
| `LABEL`        | Metadata ekler (bakımcı, açıklama vb.)                       | `LABEL maintainer="..."`            |

## docker-compose.yml Anahtar Alanları

| Alan            | Açıklama                                                   |
| --------------- | ---------------------------------------------------------- |
| `services`      | Tanımlı container'lar listesi                               |
| `build`         | Dockerfile yolu ve build context                            |
| `image`         | Hazır image kullan (build yerine)                           |
| `ports`         | Port eşlemesi `host:container`                              |
| `volumes`       | Dosya/dizin paylaşımı `host:container`                      |
| `env_file`      | `.env` dosyasından değişken yükle                           |
| `environment`   | Satır içi ortam değişkenleri                                |
| `networks`      | Container'lar arası ağ tanımı                               |
| `depends_on`    | Başlatma sırası bağımlılığı                                 |
| `restart`       | Çökme politikası (`no`, `always`, `unless-stopped`)         |
| `profiles`      | İsteğe bağlı servis grupları                                |
| `healthcheck`   | Sağlık kontrolü tanımı                                      |
| `shm_size`      | Paylaşılan bellek boyutu (Chromium için önemli)              |
