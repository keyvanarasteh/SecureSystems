# 01 — Çekirdek (Core) Yapı: Proje Kök Dizin Referansı

> **SecureSystems** projesinin **ana klasör yapısı** ve kök dizindeki her dosyanın
> kısa açıklaması.
>
> Yazar: Keyvan Arasteh · İstinye Üniversitesi · 2026

---

## Dizin (Klasör) Yapısı

| Klasör     | Amaç                                                                                                                          |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `.agents/` | **Codex / AI agent** kuralları ve workflow dosyalarının tutulduğu dizin. Otonom kod asistanları bu klasördeki tanımları okur. |
| `.agent/`  | Alternatif agent yapılandırma dizini (`.agents/` ile birlikte kullanılır).                                                    |
| `.github/` | GitHub Actions workflow dosyaları, issue/PR şablonları ve CI/CD pipeline tanımları.                                           |
| `.vscode/` | VS Code editör ayarları — çalışma alanına özel `settings.json`, önerilen eklentiler vb.                                       |
| `docs/`    | Proje dokümantasyonu. Ders notları, mimari açıklamalar ve referans belgeleri burada tutulur.                                  |
| `src/`     | **Ana kaynak kodu.** Projenin tüm uygulama/modül kodları bu dizin altında geliştirilir.                                       |
| `test/`    | Test dosyaları — birim (unit), entegrasyon ve uçtan uca (E2E) testler.                                                        |

## Konfigürasyon & Araç Dosyaları (Dotfiles)

| Dosya                 | Ne İşe Yarar                         | Kısa Özet                                                                                                                                                                                   |
| --------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.detect-secrets.cfg` | **Secret tarama** yapılandırması     | Kod tabanında yanlışlıkla commit edilen API anahtarı, şifre vb. gizli bilgileri tespit eden `detect-secrets` aracının ayar dosyası.                                                         |
| `.dockerignore`       | **Docker build dışlama** listesi     | Docker image oluştururken kopyalanmaması gereken dosya/klasörleri belirtir (`.git`, `node_modules` vb.). Build bağlamını küçültür, image'ı hızlandırır.                                     |
| `.env.example`        | **Ortam değişkenleri** örnek şablonu | Projenin ihtiyaç duyduğu tüm ortam değişkenlerini (API anahtarları, DB bağlantıları vb.) **boş değerlerle** listeler. Geliştiriciler bunu `.env` olarak kopyalayıp kendi değerlerini yazar. |
| `.gitattributes`      | **Git dosya davranış** kuralları     | Satır sonu (LF/CRLF) dönüşümleri, büyük dosyalar (LFS) ve diff stratejileri gibi Git'e özgü dosya niteliklerini tanımlar.                                                                   |
| `.gitignore`          | **Git takip dışlama** listesi        | Git'in izlememesi gereken dosya ve klasörleri tanımlar — `node_modules/`, `.env`, `dist/`, build çıktıları vb.                                                                              |
| `.npmignore`          | **npm publish dışlama** listesi      | Paket npm'e yayınlanırken dahil edilmemesi gereken dosyaları belirtir (test dosyaları, dokümantasyon vb.).                                                                                  |
| `.npmrc`              | **npm kayıt defteri** ayarları       | npm paket yöneticisinin yapılandırması — özel registry URL'leri, cache ayarları, strict-ssl gibi seçenekler.                                                                                |
| `.prettierignore`     | **Prettier format dışlama** listesi  | Prettier kod formatlayıcısının **dokunmaması** gereken dosya/klasörleri listeler (build çıktıları, üçüncü parti kodlar vb.).                                                                |
| `.secrets.baseline`   | **Secret baseline** kaydı            | `detect-secrets` tarafından oluşturulan "bilinen gizli bilgiler" referans dosyası. Yeni taramalarda bu baseline ile karşılaştırma yapılarak sadece **yeni** sızıntılar raporlanır.          |
| `.shellcheckrc`       | **ShellCheck** yapılandırması        | Bash/Shell script linter aracı ShellCheck'in proje genelindeki kural ayarları (hangi uyarılar kapatılacak, hangi kabuk sürümü hedeflenecek vb.).                                            |

## Docker & Konteyner Dosyaları

| Dosya                        | Ne İşe Yarar                             | Kısa Özet                                                                                                                                                                                |
| ---------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Dockerfile`                 | **Ana uygulama** konteyner tanımı        | Projenin temel Docker image'ını oluşturan talimatlar — base image seçimi, bağımlılık kurulumu, uygulama kopyalama ve çalıştırma komutu.                                                  |
| `Dockerfile.sandbox`         | **Sandbox ortamı** konteyner tanımı      | İzole güvenlik test/deneme ortamı oluşturan Dockerfile. Güvenli bir şekilde kod çalıştırma, exploit deneme gibi amaçlarla kullanılır.                                                    |
| `Dockerfile.sandbox-browser` | **Tarayıcı sandbox** konteyner tanımı    | Tarayıcı tabanlı (headless browser) güvenlik testleri için özelleştirilmiş sandbox ortamı — web uygulama güvenlik taramaları, Puppeteer/Playwright testleri vb.                          |
| `Dockerfile.sandbox-common`  | **Ortak sandbox bileşenleri**            | Birden fazla sandbox Dockerfile'ın paylaştığı temel katman — ortak araçlar, sistem paketleri ve güvenlik yapılandırmaları.                                                               |
| `docker-compose.yml`         | **Çoklu konteyner** orkestrasyon dosyası | Tüm servisleri (uygulama, veritabanı, sandbox'lar) tek bir komutla (`docker compose up`) ayağa kaldıran yapılandırma dosyası. Servisler arası ağ, volume ve bağımlılık tanımları içerir. |
| `docker-setup.sh`            | **Docker ortam kurulum** betiği          | Docker ortamını ilk kez hazırlamak için kullanılan Bash scripti — gerekli image'ları çekme, volume oluşturma, izinleri ayarlama gibi ön kurulum adımları.                                |

## Proje Belgeleri (Markdown)

| Dosya            | Ne İşe Yarar              | Kısa Özet                                                                                                                                                                       |
| ---------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `README.md`      | **Proje tanıtım** belgesi | Projenin ne olduğu, nasıl kurulacağı ve nasıl kullanılacağı hakkında giriş bilgisi. GitHub/GitLab'da repo ana sayfasında otomatik gösterilir.                                   |
| `VISION.md`      | **Proje vizyonu**         | Projenin uzun vadeli hedefleri, misyonu ve stratejik yol haritası. Ekip üyelerinin "büyük resmi" anlamasını sağlar.                                                             |
| `CHANGELOG.md`   | **Değişiklik günlüğü**    | Sürüm bazında yapılan tüm değişikliklerin (yeni özellik, hata düzeltme, kırılma değişikliği) kronolojik kaydı. [Keep a Changelog](https://keepachangelog.com) formatı önerilir. |
| `CONTIBUTING.md` | **Katkı rehberi**         | Projeye katkıda bulunmak isteyen geliştiriciler için kurallar — kod stili, branch stratejisi, PR süreci, commit mesaj formatı.                                                  |
| `LICENSE`        | **Lisans** dosyası        | Projenin yasal kullanım koşulları. **MIT Lisansı** altında yayınlanmıştır — özgürce kullanılabilir, değiştirilebilir ve dağıtılabilir.                                          |
