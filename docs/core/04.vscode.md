# 04 — VS Code Yapılandırması

> `.vscode/` klasörü, editör ayarlarını ve önerilen eklentileri proje bazında
> tanımlayarak tüm ekibin **aynı geliştirme deneyimini** paylaşmasını sağlar.
>
> Yazar: Keyvan Arasteh · İstinye Üniversitesi · 2026

---

## Klasör Yapısı

```
.vscode/
├── settings.json      # Editör & formatlama ayarları
└── extensions.json    # Önerilen eklentiler listesi
```

Bu dosyalar **git'e commit edilir** — projeyi klonlayan herkes aynı ayarları alır.

---

## `settings.json` — Editör Ayarları

Projeye özel VS Code ayarlarını tanımlar. Kullanıcının **kişisel (global)
ayarlarını** ezmez, sadece bu çalışma alanında geçerli olur.

### Yapılandırma Örneği

```json
{
  // ─── Genel Editör ───
  "editor.formatOnSave": true,
  "editor.tabSize": 2,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll": "explicit",
    "source.organizeImports": "explicit"
  },
  "editor.bracketPairColorization.enabled": true,
  "editor.guides.bracketPairs": "active",

  // ─── Dil Bazlı Formatlayıcılar ───
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[rust]": {
    "editor.defaultFormatter": "rust-lang.rust-analyzer"
  },
  "[svelte]": {
    "editor.defaultFormatter": "svelte.svelte-vscode"
  },
  "[dockerfile]": {
    "editor.defaultFormatter": "ms-azuretools.vscode-docker"
  },
  "[shellscript]": {
    "editor.defaultFormatter": "foxundermoon.shell-format"
  },
  "[python]": {
    "editor.defaultFormatter": "ms-python.black-formatter"
  },
  "[markdown]": {
    "editor.wordWrap": "on"
  },

  // ─── Dosya Yönetimi ───
  "files.trimTrailingWhitespace": true,
  "files.insertFinalNewline": true,
  "files.exclude": {
    "**/.git": true,
    "**/node_modules": true,
    "**/dist": true,
    "**/target": true
  },

  // ─── Arama Dışlama ───
  "search.exclude": {
    "**/node_modules": true,
    "**/dist": true,
    "**/target": true,
    "**/.svelte-kit": true
  }
}
```

### Önemli Ayarlar Açıklaması

| Ayar                          | Ne Yapar                                                      |
| ----------------------------- | ------------------------------------------------------------- |
| `editor.formatOnSave`         | Dosya kaydedildiğinde otomatik formatla                       |
| `editor.defaultFormatter`     | Hangi eklentinin formatlayacağını belirler                     |
| `editor.codeActionsOnSave`    | Kayıtta lint düzeltmeleri ve import sıralaması uygular          |
| `files.trimTrailingWhitespace`| Satır sonu boşlukları temizler                                 |
| `files.insertFinalNewline`    | Dosya sonuna boş satır ekler (POSIX standardı)                 |
| `files.exclude`               | Dosya gezgininde gösterilmeyen klasörler                       |
| `search.exclude`              | Aramada atlanan klasörler (performans için)                     |

## `extensions.json` — Önerilen Eklentiler

Projeyi açan geliştiriciye **"Bu eklentileri kur"** bildirimi gösterir.
Eklentiler **otomatik kurulmaz**, sadece önerilir.

### Neden Gerekli?

- Dockerfile yazıyorsanız → **Docker eklentisi** olmadan editör hataları tanımaz
- Python kodluyorsanız → **Python eklentisi** olmadan intellisense çalışmaz
- Rust kullanıyorsanız → **rust-analyzer** olmadan derleme hataları görünmez

> Antigravity (Gemini) gibi AI agentlar da dahil — **her dil için ilgili
> eklentinin kurulu olması gerekir**, yoksa agent o dosya tipini anlayamaz.

### Yapılandırma Örneği

```json
{
  "recommendations": [
    // ─── Temel Araçlar ───
    "esbenp.prettier-vscode",          // Kod formatlayıcı
    "editorconfig.editorconfig",       // EditorConfig desteği
    "streetsidesoftware.code-spell-checker", // Yazım denetimi

    // ─── Docker & DevOps ───
    "ms-azuretools.vscode-docker",     // Dockerfile & Compose desteği
    "ms-vscode-remote.remote-containers", // Dev Containers

    // ─── Git & Versiyon Kontrolü ───
    "eamodio.gitlens",                 // Git geçmişi & blame
    "mhutchie.git-graph",             // Git dal grafiği

    // ─── Güvenlik ───
    "snyk-security.snyk-vulnerability-scanner", // Güvenlik açığı tarama
    "timonwong.shellcheck",            // Shell script linting

    // ─── Rust ───
    "rust-lang.rust-analyzer",         // Rust IDE desteği
    "tamasfe.even-better-toml",        // TOML dosya desteği

    // ─── Web / Frontend ───
    "svelte.svelte-vscode",            // Svelte 5 desteği
    "bradlc.vscode-tailwindcss",       // Tailwind CSS
    "dbaeumer.vscode-eslint",          // ESLint

    // ─── Python ───
    "ms-python.python",                // Python desteği
    "ms-python.black-formatter",       // Python formatlayıcı

    // ─── Yardımcı (Genel) ───
    "christian-kohler.path-intellisense", // Dosya yolu tamamlama
    "foxundermoon.shell-format",       // Shell script formatlama
    "redhat.vscode-yaml",             // YAML desteği
    "bierner.markdown-mermaid"         // Markdown'da Mermaid diagrams
  ]
}
```

### Eklenti Kategorileri

| Kategori          | Eklentiler                                                | Neden Gerekli                                          |
| ----------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| **Docker**        | `vscode-docker`, `remote-containers`                      | Dockerfile linting, compose desteği, konteyner geliştirme |
| **Güvenlik**      | `snyk`, `shellcheck`                                      | Güvenlik açıkları ve script hataları                   |
| **Rust**          | `rust-analyzer`, `even-better-toml`                       | Rust IDE, Cargo.toml desteği                            |
| **Web/Frontend**  | `svelte-vscode`, `tailwindcss`, `eslint`                  | Frontend dil desteği ve lint                            |
| **Python**        | `python`, `black-formatter`                               | Python geliştirme ve formatlama                         |
| **Git**           | `gitlens`, `git-graph`                                    | Gelişmiş git geçmişi ve dal yönetimi                    |
| **Genel**         | `prettier`, `path-intellisense`, `vscode-yaml`            | Formatlama, dosya yolu tamamlama, YAML                  |

## Ayarlar Öncelik Sırası

VS Code ayarları şu sırayla uygulanır (yüksekten düşüğe):

```
1. .vscode/settings.json       ← Proje (workspace) ayarları — EN YÜKSEK
2. Kullanıcı settings.json     ← Kişisel global ayarlar
3. VS Code varsayılanları      ← Editör fabrika ayarları
```

> Yani `.vscode/settings.json` içinde yazdığınız bir ayar, kullanıcının global
> ayarını **sadece bu proje için** ezer. Diğer projelerini etkilemez.

## Diğer Olası `.vscode/` Dosyaları

| Dosya              | Amaç                                                        | Ne Zaman Eklenir                      |
| ------------------ | ------------------------------------------------------------ | ------------------------------------- |
| `launch.json`      | Debug yapılandırmaları — hangi programı, nasıl debug ederiz   | Debug ortamı kurulduğunda              |
| `tasks.json`       | Otomatik görevler — build, test, lint komutları               | Tekrarlayan komutlar varsa             |
| `keybindings.json` | Projeye özel kısayol tuşları                                 | Nadir — genellikle gerekli değil       |
| `*.code-snippets`  | Kod parçacıkları (snippets)                                  | Sık kullanılan kalıplar tekrarlanıyorsa |

### `launch.json` Örneği

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Rust: Debug",
      "type": "lldb",
      "request": "launch",
      "program": "${workspaceFolder}/target/debug/secure-systems",
      "args": [],
      "cwd": "${workspaceFolder}"
    },
    {
      "name": "Node: Debug",
      "type": "node",
      "request": "launch",
      "runtimeExecutable": "bun",
      "args": ["run", "dev"],
      "cwd": "${workspaceFolder}"
    }
  ]
}
```

### `tasks.json` Örneği

```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Build (Rust)",
      "type": "shell",
      "command": "cargo build",
      "group": { "kind": "build", "isDefault": true }
    },
    {
      "label": "Test (All)",
      "type": "shell",
      "command": "cargo test && bun run test",
      "group": { "kind": "test", "isDefault": true }
    }
  ]
}
```

## Özet

```
.vscode/
├── settings.json       → Editör DAVRANIŞlarını kontrol eder
│                         (formatlama, kayıtta düzeltme, dışlama)
│
├── extensions.json     → Gerekli EKLENTİLERİ önerir
│                         (dil desteği, linter, güvenlik tarama)
│
├── launch.json         → DEBUG yapılandırmaları (opsiyonel)
│
└── tasks.json          → OTOMATİK GÖREVLER (opsiyonel)
```

> **Anahtar kural:** `.vscode/` dosyalarını git'e commit edin ki projeyi klonlayan
> herkes (ve AI agentlar) aynı araç setini kullansın. Ancak **kişisel** ayarlarınızı
> (font boyutu, tema vb.) buraya değil, global `settings.json`'a yazın.
